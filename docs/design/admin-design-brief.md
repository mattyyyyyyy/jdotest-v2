# JDO 车机电商 · 后台管理 UI 设计 Brief（给 Claude Design）

> 用途：**一份自包含的设计任务书**，可直接交给 Claude Design / 设计工具生成后台界面。
> 不需要看其它文件——本文件已把模块、页面、字段、布局、视觉规范、组件范式全部内联。
> 汇总自：admin-spec / admin-benchmark / data-dictionary / ADR-0010~0012 / design-system。

---

## 0. 一句话任务（可直接作为 Design 提示）

> 设计一套 **PC 桌面端电商后台管理系统**界面，深色专业风格（类 Linear / Vercel / shadcn dashboard），左侧分组导航 + 顶栏 + 面包屑 + 卡片化数据表格；覆盖商品、订单、用户、营销、数据看板等模块；每个列表页含搜索、状态筛选 Tab、批量操作、分页；编辑用右侧抽屉表单。中文界面。配色见下方 token。

---

## 1. 产品背景

车机电商平台「JDO」的**运营后台**，给运营 / 客服 / 财务在 **PC 浏览器**使用。
管理消费端(车机商城)的商品、订单、用户、营销活动等数据。

**重要约束**：
- 这是**桌面 Web 后台**，用常规桌面密度（紧凑表格、32–40px 控件）。
- **不要**套用车机端的"大按钮 88px / 行车态降级"那套约束——那是消费端(车机)的规则，后台不需要。
- 中文界面；数据表格密集型；效率优先。

### 字体 / 字号 / 间距 / 圆角
- 字体：`PingFang SC / HarmonyOS Sans / Noto Sans CJK SC`；数字/金额用等宽 mono。
- 字号：正文 14px，表头 13px，页面标题 20px，KPI 数字 28–32px。
- 间距：8pt 栅格（4/8/12/16/24）。卡片内边距 20–24px。
- 圆角：卡片 12–14px，按钮/输入 8px，徽章 999px(胶囊)。
- 阴影：克制，卡片用 1px 边框 + 极弱阴影。

## 3. 整体布局（三段式）

```
┌──────────┬──────────────────────────────────────────────────┐
│          │ 顶栏 h56: 面包屑(后台/当前模块)   全局搜索  🔔  角色头像 │
│ 侧栏 w240 ├──────────────────────────────────────────────────┤
│ 分组导航  │ 主区:                                              │
│          │  ┌ 标题行: 模块名 + 共N条           [+ 新增] ─────┐  │
│          │  │ 状态筛选 Tab: 全部 / 已上架 / 已下架            │  │
│          │  │ (选中行时) 批量条: 已选N项  批量删除 批量上/下架 │  │
│          │  ├────────────────────────────────────────────┤  │
│          │  │ 数据表格(卡片包裹, sticky 表头, hover 行)      │  │
│          │  │  ☑  图  名称  分类  价格  库存  状态  操作       │  │
│          │  ├────────────────────────────────────────────┤  │
│          │  │ 分页: 第 1/N 页    [上一页][下一页]            │  │
│          │  └────────────────────────────────────────────┘  │
└──────────┴──────────────────────────────────────────────────┘
                                          编辑→右侧抽屉表单(w420)
```

- **侧栏**：顶部 Logo「◆ JDO 后台」；分组标题(小号大写灰字) + 菜单项(图标+文案)；当前项高亮(左侧品牌色竖条 + 背景加深)；底部显示当前角色。
- **顶栏**：左侧面包屑；右侧全局搜索框 + 通知铃 + 角色头像。
- **抽屉表单**：从右滑入，半透明遮罩；字段分组；底部「保存 / 取消」。

## 5. 各页面规格（列表列 + 行操作 + 表单字段）

> 规律：列表页 = 表格(下列"列") + 行操作(编辑/删除 + 布尔徽章可点切) + 顶部 [新增]；编辑 = 抽屉表单(下列"表单字段")。
> 布尔字段在表格里显示成**可点击徽章**(绿=正向/灰红=负向)；金额显示 `¥X.XX`；分类显示中文名;枚举显示中文。

### 5.1 运营看板（首页）
KPI 卡片网格(2×4)：PV 浏览量、UV 访客、订单总数、GMV(¥)、车机入口订单、手机入口订单、行车态切换次数、+1 预留。下方可放趋势图/待办区。

### 5.2 商品管理 ★(最高频)
- 列：图(缩略图) / 商品ID / 商品名称 / 分类 / 现价(¥) / 原价(¥) / 库存 / 销量(万) / 上架状态(徽章)
- 状态 Tab：全部 / 已上架 / 已下架
- 行操作：编辑、删除、点状态徽章切上/下架
- 批量：批量上架 / 批量下架 / 批量删除
- 表单字段：**商品图片(上传文件 + 预览，或填 URL)**、商品名称、分类(下拉)、现价(元)、原价(元)、库存、角标文案、上架(开关)

### 5.3 分类管理
- 列：分类ID / 分类名 / 图标 / 排序
- 表单：分类名、图标(bolt/wrench/cookie/luggage/car/phone/sparkles)、排序
- 7 大场景：能量补给/爱车养护/一路吃喝/远行出差/车内好物/24h救援/严选好物

### 5.4 Banner 横幅
- 列：ID / 主标题 / 副标题 / 配色 / 启用(徽章)
- 表单：主标题、副标题、配色(blue/emerald)、图 URL、启用

### 5.5 推荐位
- 列：ID / 角标 / 标题 / 跳转场景(分类名) / 启用
- 表单：角标、标题、副文、跳转场景(下拉分类)、启用

### 5.6 订单管理 ★
- 列：订单号 / 用户 / 商品清单 / 金额(¥) / 状态(徽章) / 入口(车机/手机) / 下单时间
- 状态 Tab：全部 / 待支付 / 已支付 / 配送中 / 已完成 / 已取消 / 退款中…
- 行操作：编辑(改状态)、(可加)发货/详情
- 表单：状态(下拉)、入口渠道(下拉)
- 状态中文：待提交/待支付/已支付/配送中/已完成/已取消/已过期/退款中/已退款

### 5.7 售后
- 列：售后单号 / 关联订单 / 原因 / 状态(待审/通过/拒绝)
- 表单：状态(下拉)

### 5.8 物流
- 列：订单号 / 运单号 / 状态 / 轨迹
- 表单：运单号、状态

### 5.9 用户管理
- 列：用户ID / 手机号(脱敏) / 昵称 / 积分 / 余额(¥) / 账号状态(正常/已封禁)
- 表单：昵称、积分、封禁(开关)

### 5.10 评价管理
- 列：ID / 商品 / 评分 / 内容 / 显示状态(显示/已隐藏)
- 表单：隐藏(开关)

### 5.11 优惠券
- 列：ID / 券名 / 类型(满减/折扣) / 面额 / 门槛(¥) / 剩余张数 / 启用
- 表单：券名、类型(下拉)、面额、门槛、剩余、启用

### 5.12 自提点
- 列：ID / 名称 / 地址 / 营业时间 / 营业状态
- 表单：名称、地址、营业时间、营业(开关)

### 5.13 账号 / 角色（系统）
- 列：ID / 账号 / 角色(超管/运营/客服/财务)
- 表单：账号、角色
- 配套「系统配置」页：行车态车速阈值(km/h)、停车退出秒数、行车态降级Banner(开关)

## 6. 复用组件 / 交互范式（设计时统一）

| 组件 | 规格 |
|---|---|
| **数据表格** | 卡片包裹圆角；表头 sticky、灰字；行 hover 高亮、底细分隔线；首列多选 checkbox；末列右对齐操作链接(编辑蓝/删除红) |
| **状态筛选 Tab** | 胶囊按钮组，选中=品牌色实心，其余=深灰；置于表格上方 |
| **批量操作条** | 选中任意行后出现：「已选 N 项 · 批量删除 · 批量上/下架 · 取消选择」 |
| **分页** | 表格底部：第 X/N 页 + 上/下一页按钮(禁用态变暗) |
| **状态徽章** | 胶囊：绿(已上架/已支付/通过)、红(下架/取消/拒绝)、灰(中间态)；商品/Banner 的徽章**可点击直接切换** |
| **抽屉表单** | 右侧滑入 w420，遮罩；字段=label(小灰) + 控件；金额输入填"元"、下拉用于分类/状态/渠道、开关用于布尔、**图片字段=预览缩略图 + 上传按钮 + URL 输入** |
| **KPI 卡片** | 大数字(品牌色) + 小标签(灰)，卡片网格 |
| **空 / 加载 / 错误态** | 空="暂无数据"居中灰字；加载=骨架；错误=红条提示 |
